# QAR — 質問に答えるだけで、提案が返ってくるシステム

> **Q**uestion, **A**nswer and **R**esult
> あるテーマについて利用者に質問し、その回答から提案をする Web システム。
> 2002年に試作し、20年後に、LLM を使って作り直しました。

![QAR の全体像](docs/img/concept-ui.png)
<sub>画面と処理の流れの全体像です。図の中の「ローカルLLM」や「今後の拡張（構想）」など、未実装・構想の部分は、[2.1](docs/02-architecture.md#21-全体像画面と処理の流れ)で現行版との対応を示しています。</sub>

## これは何か

- **2002年**：Java アプレットと PostgreSQL で試作しました。候補ごとの点数を掛け合わせて順位を出す方式です。データの準備が追いつかず、固定の評価では多様な希望に応えにくく、実用には至りませんでした。
- **現在**：Vue.js と Flask で作り直し、**OpenAI・Gemini・Groq などの複数の LLM を切り替えて**、質問の生成と提案を行います。GCP 上で稼働しています。
- 取り組んでいること：**AI の仕様変更に、設計とテストで追従する**こと。そして、**決定的なスコア計算と LLM を組み合わせた**、QAR 独自の推薦方式に発展させることです。

## 実装状況

| 領域 | 状態 |
|---|---|
| 質問に答えて提案を受ける対話の流れ（固定の質問／AI が作る質問） | 実装済み |
| テーマと指示を与えて、質問と提案を AI に作らせる汎用の画面 | 実装済み |
| 複数の AI 提供元の切り替え（OpenAI・Gemini・Groq） | 実装済み |
| 偽の AI を使った自動テスト／実際の AI を使った回帰テスト | 実装済み |
| 自前 AI の接続口 | 枠のみ（現状はダミー応答） |
| 旅行先データベース・RAG | 開発中（未実装） |
| 2002 年版の決定的なスコア計算の再導入 | 計画中（[参考実装](reference/qar_ref/scoring.py)で方式を検証） |

現状の課題は、**既存の Web 検索や一般的な AI の利用と、まだ十分に差別化できていない**ことです。
この課題への答えとして、[9 章](docs/09-roadmap.md)の方針を取っています。
