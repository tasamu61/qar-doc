# 3 機能と画面遷移

## 3.1 画面

| 画面 | 内容 |
|---|---|
| 旅行先デモ | 「質問開始」で、**固定の質問**が表示される。回答後、**使いたい AI を選んで送信**すると、提案が表示される |
| テーマ指定の画面 | 利用者が、**テーマ**、**質問の作成指示**、**提案作成時の指示**、**回答者へのアドバイス**を入力する。AI を選んで質問を作らせ、回答後に提案を受ける |
| 2002 年版の資料 | 2002 年に作った設計資料（[アーカイブ](../archive/2002/index.html)） |

## 3.2 質問の種類

| 種類 | 入力 |
|---|---|
| 単一選択 | 選択肢から 1 つ |
| 複数選択 | 選択肢から複数 |
| 文字入力（1 行） | 出発地などの短い入力 |
| 文字入力（複数行） | 自由記述 |

## 3.3 提案の内容

提案は、複数の**候補**で構成されます。各候補は次の項目を持ちます。

| 項目 | 内容 |
|---|---|
| 候補名 | 提案する名称 |
| スコア | 0〜100 の、おすすめ度（現行版では AI が出す） |
| 説明 | 候補の説明と、おすすめの理由 |
| 参考 URL | 参考にできるページ（検索へのリンクも付く） |

結果が**参考情報である旨の注意書き**を、画面に表示します。

## 3.4 操作の流れ

```mermaid
sequenceDiagram
  participant U as 利用者
  participant V as 画面
  participant S as サーバー
  participant A as AI 提供元
  U->>V: 開始（旅行デモ／テーマを入力）
  V->>S: 質問を要求
  alt 固定の質問
    S-->>V: 固定の質問
  else AI が作る質問
    S->>A: 質問の生成を依頼
    A-->>S: 質問（JSON）
    S-->>V: 検証した質問
  end
  U->>V: 質問に回答、AI を選んで送信
  V->>S: 回答を送信
  S->>A: 提案の生成を依頼
  A-->>S: 提案（JSON）
  S-->>V: 検証した提案
  V-->>U: 候補、スコア、説明、参考 URL
```

## 3.5 汎用性

画面の入力（テーマと各種の指示）を変えるだけで、旅行以外のテーマでも、質問と提案を作れます。
旅行は、最初の題材です。
