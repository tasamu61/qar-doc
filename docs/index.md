## 用語

| 用語 | 意味 |
|---|---|
| QAR | Question, Answer and Result（2002 年版での定義） |
| 提供元 | OpenAI、Gemini、Groq など、LLM を提供する API |
| 回帰テスト | 変更や外部の仕様変更で、これまでの動作が壊れていないかを確かめるテスト |
| 決定的 | 同じ入力なら、いつも同じ結果になること |
