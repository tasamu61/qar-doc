# 10 技術スタックと役割

## 10.1 技術スタック

| 領域 | 使用技術 |
|---|---|
| 画面 | Vue.js 3、HTML、CSS |
| サーバー | Python 3.12、Flask、Flask-Limiter（利用制限）、gunicorn |
| 外部 API | OpenAI、Gemini（Google）、Groq の各 API |
| 稼働環境 | Google Cloud（GCP） |
| テスト | Python 標準の unittest（偽の AI による自動テスト）、実際の AI による回帰テストのスクリプト |
| 開発管理 | Git |
| 2002 年版 | Java（アプレット）、CGI、PostgreSQL、Apache、Linux |
